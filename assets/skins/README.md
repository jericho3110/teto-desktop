# Skins

A skin is a folder with two files:

| File | What it is |
| --- | --- |
| `<name>.svg` | the art: a layered SVG whose parts have ids (`head`, `drill-L-3`, …) |
| `manifest.json` | the **contract** between the art and the code: which ids are which body part and what each face looks like |

The UI (`typescript/ui/src/skin.ts`) reads only the manifest's names, never
hard-coded ids, so a new skin with different art works without code
changes. On load the SVG is **sanitized**: scripts, event handlers, links
and external images are stripped (see `typescript/ui/src/sanitize.ts`).

## `teto-chibi/manifest.json`, field by field

```json
{ "name": "...", "version": 1, "svg": "teto.svg", "size": [300, 400], ... }
```

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | string | shown in logs |
| `version` | number | manifest format version; bump it if the format changes so old code can refuse new skins |
| `svg` | string | the SVG file name, next to the manifest |
| `size` | `[width, height]` | the SVG's `viewBox` size in SVG units |
| `parts` | object | the rotatable body parts. Each: `id` (SVG element id) + `pivot` `[x, y]`, the point it rotates around |
| `parts.head` | | the whole head group (face, hair, eyes) |
| `parts.armL` / `parts.armR` | | arms; pivots `[0,0]` because each arm group is already translated to its shoulder |
| `parts.ahoge` | | the curl on top |
| `eyes.groups` | string[] | ids of the left/right eye groups |
| `eyes.states` | string[] | each eye group has children with class `eyes-<state>` (`open`, `closed`, `happy`, `half`); exactly one is visible |
| `eyes.look` | string | class of the iris group that slides toward the cursor |
| `eyes.lookRange` | number | how far the irises may slide (SVG units) |
| `mouth.group` / `mouth.states` | string / string[] | like eyes: children with class `mouth-<state>` (`smile`, `talk`, `grin`, `o`, `flat`) |
| `blush` | string[] | ids of the blush ellipses; their opacity comes from the expression |
| `fx` | string[] | ids of effect overlays (`fx-sweat`, `fx-question`, `fx-sparkle`, `fx-zzz`), hidden unless an expression lists them |
| `chains` | array | things that dangle and get physics. Each: `prefix` (ids are `<prefix>-0` … `<prefix>-(joints-1)`, **nested** inside each other), `joints` (count), `mirror` (true for the right drill, which is drawn with `scale(-1,1)`) |
| `physics` | object | parameters for the C++ spring chain: `stiffness` (pull back to shape), `damping` (lose energy), `falloff` (each joint toward the tip is this much floppier), `gravity` (px/s²) |
| `expressions` | object | one entry per face: `neutral happy excited sad worried confused smug sleeping thinking` |
| `credits` | string | who made the art and the character's rights |

### An expression

```json
"happy": { "eyes": "happy", "mouth": "grin", "blush": 0.75, "fx": [], "headTilt": 3, "ahoge": 6 }
```

| Field | Required | Meaning |
| --- | --- | --- |
| `eyes`, `mouth` | yes | which state to show (must be in `eyes.states` / `mouth.states`) |
| `blush` | yes | blush opacity 0..1 |
| `fx` | yes | effect overlay ids to show |
| `headTilt` | yes | degrees; + tilts toward the viewer's right |
| `ahoge` | yes | degrees of the curl (negative = droopy) |
| `headDrop` | no | px the head sinks (sad, sleepy) or rises (smug) |
| `hop` | no | bounce in place (excited) |
| `arms` | no | degrees both arms raise outward |
| `lookUp` | no | eyes look up (thinking) |

The TypeScript types for all of this are `SkinManifest` and `Expression`
in `typescript/ui/src/types.ts`; the compiler checks the code that reads
the manifest, but not the JSON file itself (a JSON Schema could; see
[docs/FILE_TYPES.md](../../docs/FILE_TYPES.md#whats-a-json-schema)).

## Making a new skin

1. Copy `teto-chibi/` to `my-skin/`.
2. Redraw the SVG, keeping the ids and classes listed in the manifest
   (or change the manifest to match your ids).
3. Change `skin: "teto-chibi"` in `rust/shell/src/lib.rs` (or open the dev UI with `?skin=my-skin`).
4. Run the UI and check the browser console for "removed unsafe markup" warnings.
