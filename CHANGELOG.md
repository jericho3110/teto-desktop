## [Unreleased]

### Added
- Go brain daemon: drives Claude Code headless (`stream-json`), streams
  replies over Server-Sent Events, turns Claude's permission requests into
  Allow/Deny prompts (fail closed), `/remind` command, token auth + CORS.
- Python mood engine: lexicon-based reply → emotion over JSON lines.
- C++ spring-chain hair physics compiled to freestanding WebAssembly (1.4 KB).
- TypeScript UI: skin loader, animator (blink, breathe, talk, emotions,
  cursor-following eyes, waving), speech bubble with permission cards,
  command bar with history.
- JavaScript quirks: greetings, poke, sleepy, bread.
- Original chibi Teto-style skin generated by `tools/skin_gen/gen_teto.py`,
  with 9 expressions and effect overlays.
- Tools: live brain smoke test, headless-Edge UI probe.
- Docs: README, architecture, protocol, physics, learning path,
  conventions, libraries.
