# Conventions

## Layout

- **One top-level folder per language** (`c/ cpp/ csharp/ go/ java/
  javascript/ python/ rust/ typescript/`), and inside it **one folder per
  component**, named after its job (`go/brain`, `python/mood`).
- Each language folder has `README.md`, `CHANGELOG.md`, `docs/CONCEPTS.md`
  (and `docs/ARCHITECTURE.md` when the component needs one).
- Language-neutral things live at the top: `assets/` (skins), `docs/`
  (workspace docs), `LICENSE`.
- Files built from other languages are **copied in, never committed**:
  `typescript/ui/public/` is generated by `scripts/sync-assets.ts`.
- Tests sit where each language expects them: `*_test.go`, `test_*.py`,
  `*.test.ts`, `cpp/physics/test/`, `java/reminders/test/`,
  `c/win32hooks/tests/`, `csharp/Companion.Tests/`, `#[cfg(test)]` modules in Rust.

## Naming

| Language | Style |
| --- | --- |
| Go | `MixedCaps`; exported = capitalized |
| Python | `snake_case`, `UPPER_CASE` constants |
| TypeScript/JS | `camelCase`, `PascalCase` classes, one class per file |
| C++ | `snake_case` functions, `PascalCase` types, `kConstant`, members end in `_` |
| C | `teto_` prefix for exported functions, `g_` for file globals, `TETO_` macros |
| Rust | `snake_case` functions/modules, `PascalCase` types, `SCREAMING_CASE` consts |
| Java | `camelCase` methods, `PascalCase` classes, package `teto.reminders` |
| C# | `PascalCase` types and members, `_camelCase` private fields, namespace `Teto.Companion` |
| Protocol | event `type`s and JSON keys `snake_case`; Tauri payloads `camelCase` |
| SVG ids | `kebab-case` with side suffix: `drill-L-3`, `arm-R`, `fx-sweat` |

## Rules

- **Standard library first.** New dependency → a row in [LIBRARIES_AND_BUILTINS.md](LIBRARIES_AND_BUILTINS.md).
- **Protocol changes** update both sides and [PROTOCOL.md](PROTOCOL.md) in one commit.
- **New language concept** → explain it in that language's `docs/CONCEPTS.md`.
- **Pure logic where possible** (no I/O, time passed in), so it can be unit-tested.
- **Security rules** ([SECURITY.md](SECURITY.md)): text never HTML; every
  localhost endpoint behind Host + token checks; fail closed; validate at
  every language boundary; `unsafe` only with a `// SAFETY:` comment.
- **Warnings are errors** everywhere it's available: `-Werror` (C, C++,
  javac), `TreatWarningsAsErrors` (C#), `clippy -D warnings` (Rust), `go vet`, `tsc --strict`.

## Checks before committing

```text
python main.py test        # every language + links + security; exit code 0 = all passed
```

It runs `gofmt`/`go vet`/`go test`, the Python tests, the C++ build +
tests, `tsc` + Node tests, `javac -Xlint -Werror` + Java checks, the C
tests, `dotnet test`, `cargo fmt`/`clippy`/`test`, and the link checker.

## Commits

- Summary: imperative, ≤ 72 characters, no `feat:` prefix; prefix the
  component when it's about one: `go/brain: Add /cancel`.
- Body: *why*, related changes as `-` bullets, then how it was verified.
- One logical change per commit. Never commit secrets, tokens, `.env`,
  or real data from your machine.
